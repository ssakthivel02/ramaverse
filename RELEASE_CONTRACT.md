# RamaVerse Flagship Release Contract

## Isolation
- Legacy production: `ssakthivel02/sitarama-legacy`.
- New flagship: `ssakthivel02/ramaverse`.
- Never overwrite or repoint SitaRama while flagship validation is incomplete.

## Release gates
1. Exact-head CI green.
2. GitHub Pages deployment green on `main`.
3. Repository Pages URL smoke passes.
4. Only then configure the final RamaVerse production hostname.
5. Verify HTTPS, navigation, PWA/offline shell, responsive layout and rollback path.

## Content boundary
Source text, editorial explanation, tradition, historical evidence and generated AI guidance must remain visibly distinguishable. No deterministic spiritual, medical, financial or safety promises.
